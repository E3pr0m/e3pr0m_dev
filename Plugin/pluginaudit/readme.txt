== Description ==

PluginAudit lists every plugin installed on your site, active or not, and shows its state: known vulnerabilities with severity and category, signs of use, available updates, PHP and WordPress compatibility, and plugins that are installed but not active.

= What this plugin does not do =

* It does not scan the code of your plugins
* It does not look for malware and does not replace a security plugin
* It cannot tell for sure that a plugin is unused: it only reports "no sign of use found"

== Installation ==

1. Upload the `pluginaudit` folder to `wp-content/plugins/`, or install it from the Plugins screen.
2. Activate the plugin.
