Read the PHP and WordPress error logs, see which errors matter, and turn debug logging on and off from a panel.

== Description ==

LogPilot shows the end of your `debug.log` and PHP error log, highlights the errors by level with plain-language explanations, and lets administrators turn debug logging on and off without editing files.

= What this plugin does not do =

* It does not fix errors: it shows them and says where they come from
* It cannot tell you whether your site is healthy or safe
* It cannot read server logs that PHP has no access to

== Installation ==

1. Upload the `logpilot` folder to `wp-content/plugins/`, or install it from the Plugins screen.
2. Activate the plugin.
